Код опубликован в GitHub main: `f39332a9477588165d8d640b5a2c9e4e4153eb76`.
Удалённый SHA проверен после push; остальные три ветки не изменены.

а автоматический production-деплой не выполнялся. Workflow самостоятельно

Перед следующим push из старой локальной ветки нужно перенести изменения
на очищенную main, чтобы не вернуть прежнюю историю с SQLite.

Публикация подготовлена в отдельной копии
`backups/main-publication-20261028`, основанной на очищенной истории main.
Включена очищенная версия ветки коллеги отдельным родителем merge-коммита.
Все текущие файлы исходников перенесены и сверены SHA-256.
Исходная рабочая папка с индексом и локальными изменениями сохранена.

Пользователь разрешил push в main; другие общие ветки не переписываются.
Для main требуется точный force-with-lease относительно исходного
`981b12e302e58218e7fc4e796bc8689168a73578`. Если ветка изменилась,
push должен быть отклонён, а новые изменения — проверены и сохранены.

История main подготовлена без снимков SQLite. Другие ветки GitHub пока
сохраняют прежнюю историю, поэтому полное удаление снимков из всего
репозитория этим push не достигается. Старую историю нельзя сливать
обратно в очищенную ветку.
