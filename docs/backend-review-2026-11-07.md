Б11 ожидает решения команды: галереи и программы пока требуют входа, как до PR.
Существующая политика 401 для гостя закреплена тестами. Публичность без решения
команды не менялась; задачи Vercel из ТЗ остаются за фронтендом.

Опубликованные миграции из main не переписывались. Новые ревизии объединяют
локальный backfill с main, добавляют таблицы доступа и нормализуют собственные
media-ссылки. Внешние картинки не переписываются. Уже существующие немедленные
FK `NO ACTION` сохраняют ограничение удаления элементов подборок; их не удаляем
и не заменяем в релизе с добавочными миграциями.

Для воспроизведений добавлены тесты с проверкой падения до исправления: доверенные
устройства/отзыв, временные переводы, фото, общий раздел заявок, единый телефон,
Бишкекская дата и лимиты туристов. Дополнительно проверяются роли всех API-маршрутов,
скрытие хешей, срок cookie, повтор refresh и право owner на отзыв.

Важное отличие от конечного режима: `ADMIN_ACCESS_TOKEN_MINUTES` пока по умолчанию
60, поскольку старый фронт не умеет обновлять токен. После выхода нового фронта
оператор меняет значение на 15. Все настройки описаны в `.env.example` и `DEPLOY.md`.
Обязательный MFA включается только после записи секретов всем админам. Перед
мержем нужно довести этот порядок и новые настройки до Исхака.

Итоговая локальная проверка на копии без `.env`: **675 passed, 16 skipped**;
отдельно ML — **49 passed**, unit — **44 passed**. Ruff, форматирование и синтаксис
