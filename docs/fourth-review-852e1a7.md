# Проверка регрессий Kyrgyz_Go — 852e1a7

Проверены 14 находок повторного ревью. Изменения подготовлены локально; тесты намеренно не запускались.

| № | Результат |
|---|---|
| 1 | До Argon2 проверяются лимит IP и лимит неудачных входов аккаунта. Ключ аккаунта строится по ID клиента, поэтому username и email используют общий счётчик. После успешного входа счётчик ошибок сбрасывается, а адрес добавляется в список доверенных на 7 дней. Правильный пароль с недоверенного IP блокируется после достижения лимита. |
| 2 | Переводы очищаются в той же транзакции, что и изменение исходного текста, включая API и SQLAdmin. При ошибке или перезапуске пользователю показывается исходный текст. |
| 3 | В `tests/conftest.py` перевод поставлен на синхронную заглушку; тест блокировки входа обновлён под доверенный IP и предварительную проверку счётчика. Реальные вызовы Gemini из этих тестов исключены. |
| 4 | После удаления дополнительной услуги `can_confirm` принудительно выключен, пока сессия остаётся на этапе `collecting`. |
| 5 | При старте приложение сканирует неполные переводы и ставит их в очередь. Задачи объединяются по сущности и ID, очередь не теряет их при заполнении. |
| 6 | Перед вызовом переводчика сверяется исходный текст; устаревшая задача пропускается без оплаты. Повторные задачи одной записи объединяются. |
| 7 | Ошибки входа клиента учитываются по `client_id`, независимо от того, вошёл пользователь по email или username. |
| 8 | Лимит WebSocket нормализует IPv6 до `/64`, как и HTTP-лимитер. |
| 9 | Ошибки чтения схемы деплоя записываются как `schema_check_failed` с типом и кратким текстом ошибки. Несовпадение ревизий отдельно остаётся `migration_required`. |
| 10 | Список миграций читается из `alembic.ini`: `script_location`, `version_locations`, разделители путей и `recursive_version_locations`. |
| 11 | Повторный демо-сид больше не переписывает существующие демо-заявки и не удаляет дубликаты, на которые могут ссылаться другие записи. |
| 12 | Добавление задачи перевода использует неблокирующий `put_nowait`; заполнение ограниченных слотов больше не отбрасывает задание. |
| 13 | Неудачная попытка входа обновляет IP- и account-счётчики одним multi-row upsert и одним commit. |
| 14 | `generate_translations` уже принимает только исходные поля; неиспользуемого параметра `db` нет. |
