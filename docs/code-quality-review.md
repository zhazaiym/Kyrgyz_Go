Команда для повторной проверки похожих блоков:

```powershell
.venv/Scripts/python.exe -m pylint mysite scripts main.py --disable=all --enable=duplicate-code --min-similarity-lines=8 --ignore-imports=yes --ignore-signatures=yes
```

Pylint возвращает ненулевой код при замечании к рефакторингу; это не ошибка
выполнения приложения. Эти числа не означают отсутствия смысловых дублей:
CRUD-обработчики похожи, но используют разные модели, права и ответы.

## Удалено

- Семь классов без ссылок в исходниках и тестах: `AdminInputSchema`,
  `AdminUpdateSchema`, `TravelRequestInputSchema`, `TransportDetailSchema`,
  `HelicopterTourDetailSchema`, `TrekkingDetailSchema`, `RegionDetailSchema`.
  В маршрутах и OpenAPI они не использовались.
- Закомментированные старые определения About/FAQ/AboutSection в `schema.py`.
- Восемь проверок image/order в четырёх обработчиках изображений. Общий
  `StorageInput` уже отклоняет пустые обязательные строки и явный null
  для обязательных столбцов до вызова обработчика.
- Повторяющиеся строки `.dockerignore`; порядок уникальных правил сохранён.

## Что оставлено и почему

- Единственное оставшееся сообщение Pylint — проверка `trekking_id` в
  `trekking_image.py` и `trekking_program.py`. Короткая проверка принадлежности
  к существующему родителю оставлена явно в обоих обработчиках.
- Vulture ошибочно считает неиспользуемыми маршруты FastAPI, методы SQLAdmin,
  поля схем и ORM events: их вызывают декораторы/фреймворк. Параметры `cls`,
  `mapper`, `cursor`, `executemany` нужны для сигнатур callback и методов,
  даже если сами значения не читаются.
- `mysite/chain/agent.py:to_text` не имеет найденных вызовов;
  `mysite/translations/translator.py:translate_text` также не используется
  текущим проектом. Это кандидаты для автора ИИ. Сохранены, чтобы не менять
  самостоятельно принадлежащий коллеге код ИИ и переводов.
- Переводы туров и остального контента имеют похожие вызовы Gemini, но разные
  контракты результата. Сведение их в один путь требует отдельных проверок
  качества переводов; в эту очистку не включено.
- `docs/tour-conflict-snapshots/` и `docs/superpowers/plans/` — исторические
  материалы, не исполняемый код. Они исключены из Docker-контекста вместе
  с остальными docs. Резервные копии БД нужны для восстановления.
- Старые миграции обязательны для существующих баз. Удаление из-за возраста
  нарушило бы цепочку Alembic.

Полный расширенный набор Ruff по умолчанию содержит замечания к стилю,
типизации и импортам; текущая очистка не является массовым форматированием.
Это уменьшает изменения, которые пришлось бы совмещать с работой коллеги.
