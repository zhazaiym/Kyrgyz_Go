# Гостевой подбор путешествия

`POST /api/ask-ai` доступен без регистрации. Пример тела:

```json
{"context":{"destination":"Иссык-Куль","people":2,"hotel":true}}
```

Ответ: `{"answer":"Текст рекомендации"}`. Сервер формирует системный промпт
и использует существующий Gemini-клиент и `GEMINI_MODEL`. SDK читает ключ из
`GOOGLE_API_KEY`, а при его отсутствии — из `GEMINI_API_KEY`.
Ключ задаётся только в окружении сервера; передавать его в браузер, HTML,
localStorage или публичные переменные сборки нельзя. Новый провайдер не требуется.

Контекст ограничен 30 полями и 8000 символами JSON. Значения — строки, целые
числа, boolean или массивы строк. Вложенные объекты запрещены. Установлены
лимиты 5 запросов в минуту на сеть пользователя и 100 в час суммарно через
существующее хранилище лимитов PostgreSQL. Действуют AI_MAX_CONCURRENT,
ограничение длины ответа и таймаут 45 секунд. Ошибки провайдера не возвращаются
клиенту. Ответы не сохраняются в истории чата и не создают бронирования.

Типы проверяются строго: дробные числа, null и вложенные объекты не принимаются.
Ключи context ограничены 80 символами; дополнительные поля вне context запрещены.
Существующие `/chat/session`, `/chat/history/{session_id}` и WebSocket-чаты
по-прежнему требуют входа и проверяют владельца сессии. Гостевой метод не даёт
доступа к сохранённым чатам или заявкам.

Ошибки возвращаются в общем формате API:

```json
{"detail":{"code":"service_unavailable","message":"Сервис временно недоступен"}}
```

HTTP 422 означает ошибку параметров (стандартный ответ валидации FastAPI с
массивом detail), 429 — локальную квоту или квоту провайдера, 503 — недоступность
ИИ, базы лимитов, отсутствие вместимости или некорректный/заблокированный ответ,
504 — таймаут, включая сетевой таймаут SDK. При 429 возвращается Retry-After.
Успешный ответ имеет Cache-Control: no-store и содержит только answer,
без метаданных провайдера. Обрезанные ответы не выдаются за полный результат.

`examples/guest-ai.html` — готовый пример на чистом JavaScript: восстановление
и автосохранение `ai_user_context`, отправка текущих параметров, индикатор
ожидания и безопасный вывод через textContent. Если localStorage недоступен,
отправка остаётся работоспособной, но после перезагрузки данные потеряются.
Хранилище относится к конкретному браузеру и origin, не синхронизируется между
устройствами. Не сохраняйте в нём ключи и платёжные данные.

Фронтенд сайта отсутствует в этом репозитории. Перенесите пример или его логику
в репозиторий сайта, свяжите поля с реальными фильтрами. Настройте проксирование
`/api/ask-ai` в FastAPI либо задайте HTTPS URL API в `endpoint` и добавьте origin
сайта в `CORS_ALLOWED_ORIGINS`. Лимиты требуют работающую PostgreSQL и
`RATE_LIMIT_ENABLED=true`. Проверьте на сайте восстановление после обновления,
отправку без входа и отсутствие ключа в исходниках и сетевых запросах.

## Локальная серверная проверка

При заданном `TEST_DATABASE_URL` (PostgreSQL с CREATEDB) можно выполнить:

```powershell
python -m scripts.backend_smoke
```

Команда создаёт случайную временную базу, применяет миграции с нуля, запускает
Uvicorn на свободном localhost-порту, проверяет публичные чтения, защиту операций,
валидацию гостевого метода и CORS, затем останавливает сервер и удаляет только
созданные тестовые базу и медиа. К рабочим таблицам не обращается.

Для одного реального вызова задайте ключ и модель в окружении и добавьте
`--live-ai`. Без флага запросов к Gemini нет; фоновые переводы в smoke отключены.
Ключи и текст ответа не печатаются; проверяется отсутствие настроенных ключей в
HTTP-ответах и захваченных логах. `.env` автоматически этим скриптом не читается.
