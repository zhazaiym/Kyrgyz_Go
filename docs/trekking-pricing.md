## Валюта, единица и статус

В модели нет поля currency и в проекте не обнаружена установленная валюта
каталога: API.md прямо описывает это ограничение. Для этих новых черновиков
выбрана **KGS (кыргызский сом)**. Она явно записана в description на ru/en/de/zh
и в `translations._trekking_import.price_estimate.currency`. Общее значение
валюты других записей не назначалось. Схема БД не менялась.

`price_unit=per_person`: стоимость **за человека за весь маршрут**, не за день.
Для частных аналогов расчёт на четырёх взрослых. Для ID 18, 19 и 21 используются
публичные групповые тарифы: предполагается присоединение к наборной группе,
точное число участников источник не публикует. Это отражено в каждом описании.
`min_people=1` — технический default модели, а не гарантия частной поездки для
одного по цене четырёх участников. `max_people` не выдумывался.

У каждого нового Trekking на всех четырёх языках сохранена оговорка:

> Ориентировочная стоимость. Итоговая цена и состав услуг уточняются у менеджера.

Дополнительно указано, что гид, транспорт, питание и ночёвки — допущения
бюджетного сценария, а не обещание услуг нашей компании. `included` остаётся
NULL. Отзывы, рейтинги, доступные даты не добавлялись. `is_active=false` у всех 13.
