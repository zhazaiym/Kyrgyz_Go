# Обновление текущего сервера

Сервер сам забирает проверенные CI коммиты из `main`. Изменения проходят через PR;
пуш в рабочую ветку не обновляет прод. Задачи отправки исходников на старый сервер
и рабочие скрипты такого деплоя удалены из репозитория.

Актуальные команды, миграции, порядок включения MFA и новые переменные окружения
описаны в [DEPLOY.md](../DEPLOY.md). Сначала выкатывается бэкенд с флагом
`ADMIN_MFA_REQUIRED=false`, затем записываются TOTP всех администраторов, и только
после этого включается флаг. До обновления Vercel-админки время access-токена —
60 минут. Проверку работающего сервера после мержа выполняет оператор.
