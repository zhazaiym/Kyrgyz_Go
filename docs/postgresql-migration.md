# PostgreSQL

Приложение, тесты и CI используют только PostgreSQL. Файлы прежних локальных
баз и одноразовые скрипты переноса удалены после завершения объединения.

## Подключение

В `.env` обязательно задайте `DATABASE_URL`:

```dotenv
DATABASE_URL=postgresql+psycopg2://app_user:password@127.0.0.1:5432/kyrgyzgo_db
```

Для Docker используйте `host.docker.internal`, если PostgreSQL работает на
хосте. Спецсимволы пароля кодируются в URL. Другие СУБД не поддерживаются.

## Миграции

```powershell
.venv/Scripts/python.exe -m alembic upgrade head
.venv/Scripts/python.exe -m alembic current
```

История объединена в одну ветвь. Исправлены старые ревизии, удалявшие таблицы
чатов и подборок. Пустая база создаётся через `upgrade head`; рабочая база
обновляется без удаления объединённых данных.

Ревизия `20261027_0011` переносит email профилей в единую таблицу клиентов
и добавляет снимки выбранных услуг к заявкам. Перед удалением старого столбца
миграция проверяет совпадения: разные владельцы одного email или разные email
одного клиента останавливают обновление с откатом. Такие записи требуют
проверки владельцев; аккаунты автоматически не объединяются.

## Резервные копии

Перед изменением схемы выполняйте `pg_dump -Fc`, восстанавливайте через
`pg_restore` в отдельную пустую базу. Каталог `backups/` исключён из Git и Docker.
Изображения необходимо копировать отдельно.

Объединение выполнено 2026-10-27 в локальную PostgreSQL-базу `kyrgyzgo.db`.
Сохранены 25 туров, 22 отеля и 5 заявок. Добавлены 12 клиентов, 17 бесед,
24 сообщения, 26 токенов, 1 администратор и 5 категорий.
Старые 10 сообщений сохранены в `archive.legacy_chat_messages`,
их 5 чатов — в `archive.chats`. Журнал импорта хранится в `archive.import_history`.
Новый API чата этот архив не показывает.

## Тесты

`TEST_DATABASE_URL` задаёт подключение с правом `CREATEDB`. Тесты создают и
удаляют временные базы с уникальным префиксом `test_kyrgyzgo_`. Рабочая база
не очищается. В CI PostgreSQL 17 запускается отдельным сервисом.
