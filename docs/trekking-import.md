## Поля, переводы и незаполненные сведения

Модели, связи и API не менялись. Используются Trekking, TrekkingProgram,
TrekkingImage. В Trekking нет отдельных полей сезона, региона, источника и
лицензии: регион/сезон помещены в description, этапы — в route и программы;
источники и сведения об изображении сохраняются также в служебной части
существующего translations JSON у новых записей.

Данные ru/en/de/zh подготовлены вручную. Используется штатный
`mark_manual_translations`, `_source_hashes`, `_manual_fields` и `localized`;
это поддерживаемая ветка существующего механизма переводов, без новых полей,
вызовов ИИ или фоновых переводов других разделов. Русские и опубликованные
латинские топонимы фиксированы; de/zh сохраняют латинские собственные имена.
Дневные часы начала/конца не заимствованы из расписания чужого оператора.

Не заполнены:

- **Точные тарифы компании**: не подтверждены; price заполнено разрешённой
  ориентировочной оценкой, price_unit=per_person. Коммерческая доступность группы
  не подтверждается. max_people остаётся null.
- **included**: услуги компании не подтверждены. В requirements явно указано,
  что сопровождение, транспорт, питание и ночёвки пока не согласованы.
- **duration_hours, start_time, end_time**: нет единого проверенного точного
  времени выбранного варианта; сохранена длительность в днях и порядок этапов.
- **distance_km / max_altitude**: заполнены только подтверждённые величины;
  при расхождениях или отсутствии точной максимальной точки оставлены null.
- **Сложность радиального Каракольского маршрута**: у Visit Karakol одновременно
  указаны начинающие и требование опыта; сохранена пометка о необходимости
  уточнения вместо придуманной оценки.
- **Точный GPS высадки Кол-Укок**: не опубликован в выбранных источниках;
  обозначен автомобильный конец дороги в ущелье, без подмены другим вариантом
  через село Исаакеев. Перед использованием нужен точный pin местного оператора.
- **Фотографии 9 новых маршрутов**: подходящие снимки с одновременно проверенными
  местом и свободной лицензией в этой подборке не подтверждены. Фото операторов
  без явного разрешения и зимнее лавинное обучение в Жыргалане не подставлялись.

У Ала-Куля и Жети-Огуза не перенесены конфликтующие суммарные расстояния;
у Арча-Тора опубликованы 25 км суммарно и 26 км по этапам — поле пустое.
Итог маршрута Каракольских радиальных выходов — 49 км пешком, не 63 км с дорогой.
У Жыргалана проверены именно пешие показатели: Турналуу-Кёль 13.3 км / 2862 м,
Кок-Бель 12 км / 2659 м, Ууру-Тор 19 км / 3117 м.
Новые даты выездов, цены партнёров, отзывы и рейтинги не добавлялись.

## Воспроизведение

Проверка/экспорт без записи:

```powershell
python -X utf8 -m scripts.import_trekkings --expect-database kyrgyzgo.db
```

Запуск записи (уже выполнен без файла цен и безопасно завершился с блокировкой):

```powershell
python -X utf8 -m scripts.import_trekkings --expect-database kyrgyzgo.db --apply
```

После получения реальных коммерческих данных передайте JSON-файл
`--commercial-data <путь>`. Его ключи — ключи маршрутов из таблицы. Для каждого
нужны price и `approved_by_company: true`. Необязательны price_unit
(default per_person), min_people (default 1), max_people (default null).
Если расчёт не за человека, явно укажите price_unit. Фиктивные примеры цен не приводятся.
Повторно использовать цены других операторов нельзя.

Защита импорта: только PostgreSQL и loopback, точное имя базы, запрет названий
test/prod/stage и query-переопределения хоста; проверка фактического адреса сервера.
Общий advisory lock сериализует повторные импорты. Идентификация по стабильному
ключу в translations, нормализованному названию/маршруту и явным прежним названиям
для известных совпадений. Существующие строки всегда пропускаются, не обновляются.
Весь пакет новых родителей/программ/изображений записывается одной транзакцией,
только если у всех новых маршрутов заполнены обязательные коммерческие данные.
Создаваемые записи остаются неактивными черновиками; публичные GET для них
должны возвращать 404 до отдельной активации.
